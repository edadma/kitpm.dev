## Why Kit?

Kit takes the structurally important ideas from Nix — content-addressed immutable store, generations, atomic switches, closure-based GC — and omits the complexity that makes them hard to learn and teach.

<CardGrid>
	<Card title="Portable" icon="laptop">
		Runs on any POSIX system: Linux, macOS, FreeBSD, and Slix. Platform differences are handled by small, swappable adapters.
	</Card>
	<Card title="Reproducible" icon="approve-check">
		Content-addressed store with exact dependency pinning. No version ranges, no constraint solving. Every install is deterministic.
	</Card>
	<Card title="Predictable" icon="setting">
		A closed effect schema means packages declare exactly what they do to the system. No arbitrary shell scripts, no hidden side effects.
	</Card>
	<Card title="Reversible" icon="reverse">
		Every operation produces a new generation. Rollback is an atomic pointer flip plus a journaled activation diff. It always works.
	</Card>
</CardGrid>

## Two roles, one tool

- **On Slix:** the native system package manager. Owns system integration — users, services, capabilities.
- **On Linux / macOS / BSD:** a portable personal-prefix package manager. Real rollback, hermetic installs, multi-version coexistence for your own software.

The same knowledge transfers between platforms.
